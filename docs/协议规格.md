## 1. NSR 雷达通信协议 V1.2.9（湖南纳雷科技）—— TCP

### 1.1 通信参数

- **TCP：雷达作服务端，上位机作客户端**；默认端口 **50000**；雷达最多支持 5 个客户端同时连接。
- UDP：默认端口 8100（雷达主动发心跳，客户端应答）。
- 串口：**115200** / 无校验 / 无流控 / 1 停止位。
- Web socket：端口 1883（JSON 格式，不走本文档二进制协议）。

### 1.2 通用数据包格式（协议表 3-1）

| 偏移 | 字节数 | 字段 |
|---|---|---|
| 0 | 2 | 起始码 = `0xA5 0x5A` |
| 2 | 1 | 源地址 |
| 3 | 1 | 目的地址 |
| 4 | 1 | 命令码 |
| 5 | 2 | 参数长度 N（小端） |
| 7 | N | 参数 |
| 7+N | 1 | 校验和 |

- **校验和 = 从「源地址」字节开始，到参数最后 1 字节结束，所有字节累加和 & 0xFF**。
- **总帧长 = N + 8**。
- **如无特别说明，数字取小端模式**（§3.3.1）；仅 IP 地址等少量数据用大端（§3.3.2）。整形 4 字节，浮点 4 字节。
- 短浮点数（3 字节，仅用于接收机性能测试与添加坐标设置）：字节 1 最高位为符号位（0 正 / 1 负）、低 4 位为小数位（0.0~0.9）；字节 2 为整数高八位；字节 3 为整数低八位。例：−250.3 → `0x83 0x00 0xFA`。

### 1.3 通用应答包（协议表 3-2）

```
A5 5A | 源地址 | 目的地址 | 0xA2 | 02 00 | 参数1 | 参数2 | 校验和
```
- 参数 1 = 被响应功能的命令码；参数 2 = `0x0F` 成功 / `0xF0` 不成功。
- 示例：上位机发保存参数 `A5 5A 10 60 88 00 00 F8` → 雷达应答 `A5 5A 60 10 A2 02 00 88 0F AB`。

### 1.4 通信地址编码（§6.1）

| 设备 | 地址 |
|---|---|
| PC（上位机） | `0x10` |
| NSR100 / NSR100W | `0x40` |
| NSR150 | `0x60` |
| NSR50W | `0x70` |
| 其它雷达 | `0x90` |
| 广播 | `0xFF` |

### 1.6 心跳包（§4.13，命令码 0xA4）

参数长度 = 1；参数 = 心跳间隔秒数（0~255，默认 5）。TCP/UDP 双方均可主动发心跳，雷达返回通用应答（0xA2）。

### 1.7 目标信息传输（§4.14，命令码 0xA8）— 本项目核心

```
A5 5A | 源地址 | 目的地址 | 0xA8 | 参数长度M(2,小端) | 参数 | 校验和
M = 1 + N*68        // N = 目标个数
参数1 = 目标个数 N（1 字节，0~255）
参数2 = 目标列表，每目标 68 字节
```

**单个目标 68 字节布局（协议表 4-19）**

| 偏移 | 字节数 | 类型 | 字段 | 说明 / 单位 |
|---|---|---|---|---|
| 0 | 4 | unsigned int | ID | 目标 ID，0~4294967295 |
| 4 | 4 | int | type | 目标类型 0~65535 |
| 8 | 4 | float | x_speed | X 方向速度 m/s |
| 12 | 4 | float | y_speed | Y 方向速度 m/s |
| 16 | 4 | float | z_speed | Z 方向速度 m/s |
| 20 | 4 | float | x_axes | X 方向坐标 m |
| 24 | 4 | float | y_axes | Y 方向坐标 m |
| 28 | 4 | float | z_axes | Z 方向坐标 m |
| 32 | 4 | float | length | 测量距离 m |
| 36 | 4 | float | azimuth_angle | 方位角 −90~90 度 |
| 40 | 4 | float | elevation_angle | 俯仰角 −90~90 度 |
| 44 | 4 | float | SNR | 信噪比 |
| 48 | 4 | float | Peak_energy | 峰值能量（能量幅值的 dB 值） |
| 52 | 2 | unsigned short | area | 报警区域位掩码 |
| 54 | 14 | — | 保留字节 | — |

- `type`（目标协议）：`0x00` 未识别；`0x01` 人；`0x02` 车；`0x03` 树；`0x04` 船；`0xFFFF` 已删除目标。
- `area`：2 字节，**低字节在前、高字节在后**，共 16 bit；低字节第 0 bit = 第一防区，依次类推；0=无目标，1=有目标。
- **雷达目标坐标系：雷达位于坐标原点，雷达探测方向为 Y 轴正向**（§4.2）。

### 1.8 点云传输（§4.15，命令码 0xA9）

```
A5 5A | 源地址 | 目的地址 | 0xA9 | 参数长度M(2,小端) | 参数 | 校验和
表头标注 M = 4 + N*68          // 注意：正文文字误写为 1+N*68，以表头 4 字节计数为准
参数1 = 目标个数 N，占 4 字节（unsigned int，0~65535）
参数2 = 目标列表，每目标 68 字节
```

**单个点云 68 字节布局（协议表 4-21）**：ID 4B `unsigned int`；type 4B `unsigned char`(0~255)；x_speed / y_speed / z_speed / x_axes / y_axes / z_axes / length / azimuth_angle / elevation_angle / SNR / Peak_energy 各 4B `float`；area 2B `unsigned short`；保留 14B。

点云 `type`（表 4-22）：`0x00` 未识别、`0x01` 人、`0x02` 车、`0x03` 树、`0x04` 船、`0x05`（空）、`0x06` 小船、`0x07` 中船、`0x08` 大船。

> **注意**：目前 **NSR800W 的目标输出采用点云传输协议**（§1 概述）。

### 1.9 其它相关命令

- `0x03` 添加坐标设置：参数 7 字节 = 顶点编号(1, 1~4) + X 坐标(短浮点 3B) + Y 坐标(短浮点 3B)。笛卡尔坐标系下雷达位于原点，探测方向为 Y 轴正向，展示区域为矩形，四顶点从**左下角**起**顺时针**编号 1~4，需依次设置 4 个顶点。
- `0x0A` 读取雷达状态：可读雷达地址编码、固件版本号、雷达型号（参数 11，占 2 字节）等。
- `0x88` 保存参数；`0xDB` 重启系统；`0xE0/0xE1/0xE3` 参数读取/设置/临时设置；`0xFF` 设备发现。

**雷达型号表（§6.3，2 字节）**：NSR100=1/64(0x40)；NSR100W=2/96(0x60)；NSR50W=3/112(0x70)；NSR300W=4/144(0x90)；NSR100W-LD=7；NSR100W-M=8；NSR150=9；DH200=11；DH300=12；NSR300W-M=16；NSR2000=17；NSR60W=18；ETR10=19；TPD60C=21；TCR600=22；NSR200=23；NSR300W-LD=24；DH300W-BOAT=25；NSR300W-BOAT=26；NSR800W=27；NSR120=29；DCS100=30；NSR800WP=31；NSR3000=32；SUC261=33；NEC001=40；定制型号 >50000。前四个型号需同时识别两组类型值，新固件以「/」左边的值为准。

## 2. UCM221 雷达通用协议 V1.1.0 —— 本项目只取 GPS 信息

### 2.1 上传帧总览（§4.5，表 4-11）

```
A5 5A | 数据总长度L(2) | 汇总信息(20B) | 目标信息(5+14*N1) | 点云信息(5+14*N2) | 校验和(1)
```
数据总长度 L = 20 + (5+14*N1) + (5+14*N2)。校验和 = 汇总+目标+点云所有字节和的低 8 位。

> ⚠️ **文档 §4.5 原文写「雷达信息的传输采用大端模式」，但参考项目接入真机 `192.168.10.77:50000` 抓包逐字节核对后确认：上传流所有数值型字段均为小端**，仅起始码（`A5 5A / A7 7A / A8 8A / A9 9A`）作为字面字节序列保持不变。此前按「大端」解析导致真机帧无法分帧、`framesReceived` 恒为 0。
> **→ 本项目按小端解析 UCM221 上传流**，并在配置中提供 `BigEndian` 开关以备固件差异。

### 2.2 汇总信息（20 字节，起始码 `0xA77A`）

| 偏移 | 字节数 | 类型 | 字段 |
|---|---|---|---|
| 0 | 2 | Uint16 | 起始码 = 0xA77A |
| 2 | 1 | Uint8 | 汇总信息总长度 |
| 3 | 1 | Uint8 | 数据包状态 |
| 4 | 1 | Uint8 | 目标个数 N1 |
| 5 | 1 | Uint8 | 单个目标大小 |
| 6 | 1 | Uint8 | 年份偏移值（当前年 = 1900 + 偏移） |
| 7 | 1 | Uint8 | 月 |
| 8 | 1 | Uint8 | 日 |
| 9 | 1 | Uint8 | 时 |
| 10 | 1 | Uint8 | 分 |
| 11 | 1 | Uint8 | 秒 |
| 12 | 2 | Uint16 | 毫秒 |
| 14 | 2 | Uint16 | 设备 ID（与设备 IP 地址相同） |
| 16 | 2 | Uint16 | 点云个数 N2 |
| 18 | 1 | Uint8 | 单个点云大小 |
| 19 | 1 | Uint8 | 校验和 |

**数据包状态位掩码**：

| 位 | 值 | 含义 |
|---|---|---|
| Bit0 | 0x01 | 数据有效（0 无效 / 1 有效） |
| Bit1 | 0x02 | **扩展信息（IMU + GPS）存在有效标志** |
| Bit2 | 0x04 | **无人机信息存在有效标志** |

### 2.3 扩展信息模块（起始码 `0xA33A`，共 45 字节）—— 含 GPS

```
起始码(2)=0xA33A | 长度(2) | 加速度X1Y1Z1(3×Int16) | 角速度X1Y1Z1(3×Int16)
| 加速度X2Y2Z2(3×Int16) | 角速度X2Y2Z2(3×Int16)
| GPS纬度(Int32) | GPS经度(Int32) | GPS海拔高度(Int32) | GPS速度(Int16) | GPS磁偏角(Int16) | 校验和(1)
```

| 字段 | 类型 | 缩放因子 | 无效值 | 单位 / 符号约定 |
|---|---|---|---|---|
| 加速度 | Int16 ×6 | 0.004788 | −32768 | m/s² |
| 角速度 | Int16 ×6 | 0.001065 | −32768 | rad/s |
| GPS 纬度 | Int32 | **1e-7** | −2147483648 | 度，北纬为正、南纬为负 |
| GPS 经度 | Int32 | **1e-7** | −2147483648 | 度，东经为正、西经为负 |
| GPS 海拔高度 | Int32 | **0.001** | −2147483648 | 米 |
| GPS 速度（对地） | Int16 | **0.01** | −32768 | m/s，负值表示后退 |
| GPS 磁偏角 | Int16 | **0.01** | −32768 | 度，东偏为正、西偏为负 |

校验和 = 所有字节数据和的低 8 位。

### 2.4 无人机信息模块（起始码 `0xA22A`，共 39 字节）—— 含 GPS 位置 + 姿态

```
起始码(2)=0xA22A | 长度(2) | 标志(2, Uint16) | GPS纬度(Int32) | GPS经度(Int32) | GPS海拔高度(Int32)
| 相对高度(Int32) | 飞行速度VN(Int16) | 飞行速度VE(Int16) | 飞行速度VD(Int16)
| 横滚角(Int16) | 俯仰角(Int16) | 航向角(Int16) | 校验和(1)
```

**标志位**：Bit0 = GPS 位置有效标志；Bit1 = 姿态有效标志。

| 字段 | 类型 | 缩放因子 | 单位 / 说明 |
|---|---|---|---|
| GPS 纬度 | Int32 | 1e-7 | 度，北正南负 |
| GPS 经度 | Int32 | 1e-7 | 度，东正西负 |
| GPS 海拔高度 | Int32 | **0.001** | 米 |
| 相对高度 | Int32 | **0.001** | 米，无人机相对地面高度 |
| 飞行速度 VN / VE / VD | Int16 | **0.01** | m/s，朝北 / 朝东 / 朝下 |
| 横滚角 / 俯仰角 / 航向角 | Int16 | **0.0001** | **弧度**，范围 −31415~31415；横滚向右为正、俯仰向上为正、航向顺时针为正 |

### 2.5 点云记录（14 字节）

| 偏移 | 字节数 | 类型 | 字段 |
|---|---|---|---|
| 0 | 2 | Uint16 | 点云 ID |
| 2 | 4 | Float32 | 距离（m） |
| 6 | 1 | Uint8 | 信噪比 |
| 7 | 1 | Uint8 | 保留（真机实测为峰值能量） |
| 8 | 2 | Int16 | 方位角（÷100 → 弧度） |
| 10 | 2 | Int16 | 俯仰角（÷100 → 弧度） |
| 12 | 2 | Int16 | 速度（÷100 → m/s） |

点云模块起始码 `0xA99A`；点云信息总长度包含 IMU+GPS 数据。

### 2.6 目标记录（14 字节位压缩）

起始码 `0xA88A`；目标 ID 4B 低 8 位（ID=0~4095）；目标类型 `5[0:3]` Uint4（0~15）；目标置信度 `5[4:7]` Uint4（×10）；位置 X `6[0:20]` Int21（÷100 m）；位置 Y `6[21:41]` Int21（÷100 m）。

> 位序（MSB-first/Motorola vs LSB-first/Intel）存在歧义；参考项目采用 **MSB-first**。本项目只取 GPS，不依赖该假设。

### 2.7 命令协议（帧头 `0x5A 0xA5`）

```
起始码(2)=0x5A 0xA5 | 功能串(10B) | 结果(4B) | 传输方向(4B, 0=发/1=收) | 参数总长度(4B) | 参数
```
功能串：`setPara / getPara / reboot / getVer / imuCal` 等。结果码：`0` 成功 / `-1` 超出范围或命令码不存在 / `-2` 失败。网络参数读取：参数 1 = 命令码（IP `0xc6`、子网掩码 `0xfa`、网关 `0x10a`），参数 2 = 参数类型长度（默认 4）。

## 3. 基座 UM982（NebulasIV 高精度产品）—— 串口 NMEA

### 3.1 驱动事实（`E:\Projects\文档\无人机+RTK\um982_driver_v1.0.0\`）

- C 语言（Linux 参考实现，可移植），Nanoradar 2026，v1.0.0；用于 **UM982 双天线 GNSS 模块**。
- 解析 NMEA：**`RMC` / `GGA` / `VTG` / `THS`**，汇聚为统一结构 `GpsInfo`。
- 默认串口：Linux `/dev/ttyPS1` @ **460800**（`port/um982_port.h` 可改）。
- README 示例输出：`[00] lat=39.9041984 lon=116.4073984 alt=82.5m spd=0.00m/s ang=5.75deg sat=13 quality=1`
- **THS 真航向需要双天线**，单天线时自动回退到地面航向；**`THS` 优先级高于 RMC/VTG 的 course**。
- 看门狗：失联自动重发配置命令；`gpsTimeoutSec` 超时判失联；`isGpsHealthy()`。
- 可选：RMC UTC 两阶段系统校时；WGS84 → 百度 / 谷歌坐标转换（`convertToBaiduCoordinates` / `convertToGoogleCoordinates`，即 WGS84→GCJ02→BD09）。
- **串口独占**：驱动会打开串口并下发配置命令，不可与其他模块共用同一串口。

**统一数据结构（`src/um982.h:25-45`）**
```c
typedef struct { uint64_t time_us; double Lon; double Lat; float Alt; float Spd; float Ang;
                 unsigned char Satellites; unsigned char Quality; unsigned char Status; unsigned char Healthy; } GpsInfo;
typedef struct { double Lon; double Lat; float Alt; float Spd; float Ang; } Coordinates;
```

### 3.2 NMEA 语句格式（本项目解析目标，用户点名 7.1.1.3 GPGGA 与 7.1.1.11 GPRMC）

**`$--GGA`（卫星定位信息）**
```
$GPGGA,<UTC时><分><秒>,<纬度ddmm.mmmm>,<N/S>,<经度dddmm.mmmm>,<E/W>,<定位质量>,<卫星数>,<HDOP>,<海拔高度>,M,<大地水准面高>,M,<差分龄期>,<基准站ID>*<校验>
```
定位质量：0=无效；1=单点定位；2=差分定位；4=RTK 固定解；5=RTK 浮动解。

**`$--RMC`（推荐最小定位信息）**
```
$GPRMC,<UTC时间>,<状态A/V>,<纬度ddmm.mmmm>,<N/S>,<经度dddmm.mmmm>,<E/W>,<对地速度(节)>,<对地航向(度)>,<UTC日期ddmmyy>,<磁偏角>,<磁偏方向>,<模式指示>*<校验>
```

- 纬度 `ddmm.mmmm` → 度 = `dd + mm.mmmm/60`；经度 `dddmm.mmmm` → 度 = `ddd + mm.mmmm/60`。
- RMC 速度为**节**，1 节 = 1.852 km/h = 0.514444 m/s。
- NMEA 校验：句子 `$` 与 `*` 之间所有字符 XOR，与 `*` 后两位十六进制比较。

### 3.3 待现场确认
